Bank Account Management System
Overview

The Bank Account Management System is a simple Java project that allows users to perform basic banking operations. It is designed to demonstrate the use of object-oriented programming concepts such as classes, objects, methods, constructors, and user input.

Features
Create a bank account
Deposit money
Withdraw money
Check account balance
Display account details
Validate transactions (prevent invalid withdrawals)
Technologies Used
Java
Object-Oriented Programming (OOP)
Scanner Class for User Input
Project Structure
BankAccountProject/
│── BankAccount.java
│── Main.java
└── README.md
How to Run
Download or clone the project.
Open it in any Java IDE (Eclipse, IntelliJ IDEA, or VS Code).
Compile the Java files.
Run the Main.java file.
Follow the on-screen instructions.
Sample Operations
Create a new account
Deposit ₹1000
Withdraw ₹500
Check available balance
Display account information
